# 09: Tags with autocomplete

**What to build:** Tagging without the cost of managing tags. Tags are free-form text on a todo, with a registry of previously used tags powering autocomplete.

**Blocked by:** 08 — Seven views as routes, with navigation and empty states

**Status:** ready-for-agent

- [ ] The tag input suggests tags used elsewhere as the user types
- [ ] A todo can carry several tags at once
- [ ] Clicking a tag shows the todos carrying it
- [ ] Tags look and behave the same everywhere they appear
- [ ] A todo with no tags shows nothing rather than an empty container
- [ ] Suggestion order and matching are covered by unit tests
