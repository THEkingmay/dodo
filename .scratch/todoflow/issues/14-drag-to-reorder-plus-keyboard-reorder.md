# 14: Drag to reorder, plus keyboard reorder

**What to build:** Manual ordering from TOR section 15 — with a pointer drag *and* a keyboard equivalent, because a pointer drag alone leaves keyboard and screen-reader users unable to reorder at all.

**Blocked by:** 07 — Sort and search the list

**Status:** ready-for-agent

- [ ] A todo can be dragged to a new position, and that order persists across a reload
- [ ] The list reorders smoothly as items move
- [ ] A focused todo can be moved up and down with Alt and the arrow keys, with no pointing device involved
- [ ] Each reorder announces the new position and the total number of todos
- [ ] Reordering works with the pointer, with the keyboard, and with both together
- [ ] Reordering is offered only where a manual order makes sense, and doing it makes manual order the active sort
- [ ] Ordering is consistent with the sorted views rather than fighting them
