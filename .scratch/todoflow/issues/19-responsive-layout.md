# 19: Responsive layout

**What to build:** The layout section of the TOR — sidebar on desktop, a slide-in drawer on a phone, and no functionality lost on the way down.

**Blocked by:** 18 — Motion and reduced-motion

**Status:** ready-for-agent

- [ ] On desktop the sidebar sits beside the content
- [ ] Below the tablet width the sidebar collapses and the content fills the width
- [ ] On a phone, a top bar opens a slide-in drawer holding navigation, search and tag navigation
- [ ] A single floating button creates a todo on a phone and is reachable by keyboard
- [ ] The drawer closes on Escape and returns focus to its trigger
- [ ] The drawer and the sidebar present the same information, leaving no gap in functionality on a phone
- [ ] Nothing scrolls horizontally at 320 pixels wide
- [ ] The layout holds its shape on iOS Safari
