# 21: README, deploy workflow, and release checks

**What to build:** Shipping it — a working public address, and a README honest enough that a reviewer trusts the rest of the claims.

**Blocked by:** 20 — Accessibility hardening

**Status:** ready-for-agent

- [ ] The app is reachable at a stable GitHub Pages address
- [ ] Refreshing a deep link, including one carrying search or sort parameters, works rather than 404ing
- [ ] The production build is verified in CI before it is deployed
- [ ] The README opens with a screenshot or short recording and a plain statement of what the app is
- [ ] The README lists the features, the tech stack, and how to run it locally
- [ ] The README states the real limitations: no cross-device sync, no undo across a reload, and CSV export-only
- [ ] The README reports the actual bundle size rather than claiming the app is small
- [ ] The README points at the command palette and the keyboard shortcut help, so a reviewer can find both quickly
